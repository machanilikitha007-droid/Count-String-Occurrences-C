# Count String Occurrences in C

**Author:** M.Likitha

## Description

This program stores multiple words in an array of strings and counts
how many times a given word appears in the array.

## File

string_occurrence.c

## Concepts Used

- Array of strings
- Character arrays
- `strcmp()`
- Searching
- `for` loop
- Counter variable

## How to Run

gcc string_occurrence.c -o string_occurrence
./string_occurrence

## Sample Output

Enter 6 words:
Word 1: apple
Word 2: mango
Word 3: apple
Word 4: orange
Word 5: apple
Word 6: banana

Enter word to search: apple
'apple' occurs 3 time(s).
